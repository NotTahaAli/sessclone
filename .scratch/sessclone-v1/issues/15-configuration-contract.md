# 15: Configuration contract

**What to build:** The full list of environment variables the server and the Collector read, so a self-hoster can stand the product up without reading source.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Every variable named, with its default and whether it is required
- [ ] Database, storage, and base URL all configurable; no provider hard-coded
- [ ] Collector-side variables documented alongside server ones
- [ ] An example environment file committed, carrying no real values
