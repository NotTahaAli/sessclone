SessClone collects Claude Code usage from every machine your team works on and
puts it in one place, so an Org can see what it is spending — per Member, per
Project, per Device — and, when a Member opts in, download the raw session
logs to learn from them.

## What is collected

A Claude Code plugin, the **Collector**, runs on each machine and reports
**usage only**: token counts, models, timings, and the Session, Project and
Device they belong to — plus, per Turn, the working directory it ran in, the
git branch, and the git remote normalised into a Project key. Never a prompt,
never a file's contents.

Transcripts — the raw session logs, which do contain both — are a separate
upload that stays off until a Member turns it on.
